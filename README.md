# Bookmark Manager

On a random Sunday, I opened up my bookmark tab in chrome, What did I see? I saw a bunch of link's, none of them telling their purpose to me, It was hard and time consuming to find the perfect site, Which is what compelled me to make this Bookmark Manager. In this bookmark manager you can add your own links, organise them with tags and search up a certain website when you need to visit it!

# Features

1. Add bookmarks with URL and tags
2. Auto-fetch favicon - Automatically fetches the symbol used to represent the website
3. Delete and edit bookmarks - You change the URL that a bookmark may lead too and delete the bookmark if you don't need it anymore
4. Tag filtering - You can set tags to bookmarks to automatically filter them into seperate categories
5. Search - Search for certain website or bookmark
6. Sort by date and domain - Sort by the date added or the domain name of the website
7. Keyboard shortcuts - press "Enter" to add a bookmark once you have added a URL and press "/" to move to the next box ("/" doesn't work in the URL box)
8. Bookmark count - Shows the number of bookmarks you've added!
9. Favourite/pin bookmarks - If you find a bookmark important, Mark it with a star!
10. Copy URL button - Press the copy button beside a bookmark to copy the URL of it
11. Import/export JSON - Import your own list of bookmarks using a .json file and export all the bookmarks on the site in another .json file
12. Dark/light mode toggle - Themes! select dark mode or light mode
13. localStorage persistence - Saves all your bookmarks locally! You can find them with ease!
14. Double detection feature - If a URL already exists, The website will warn you about it!

# Tech Stack

This website uses 3 different coding languages with different purposes, The main.html file is used to structure the website and create the visual elements. The style.css file is used to make those visual elements in main.html look good. The app.js file makes the entire website work and functions as the backend.

# How to Contribute

1. clone this github repo
2. make the changes you want to make (You can implement visual changes in style.css, structure changes in main.html and backend/logic changes in app.js)
3. test the website to make sure you didn't break anything, Test with a proper set of test data including abnormal, extreme and boundary data.
4. submit a pull request here once you are done implementing your changes!
